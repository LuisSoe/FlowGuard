# FlowGuard

FlowGuard is a Business Cashflow Prediction & Monitoring Web App** designed to help small and medium enterprises (SMEs) proactively manage, monitor, and predict their business cashflow.

FlowGuard aims to help small businesses:

1. Avoid running out of cash
2. Make data-driven financial decisions
3. Reduce reliance on error-prone spreadsheets

#Vision 
To become a **data-driven financial decision assistant** for SMEs, enabling smarter and more structured cashflow management.

Insights:

1. Many small businesses still rely on manual spreadsheets → prone to errors
2. Difficult to predict future cashflow (30–90 days ahead)
3. Lack of early warning systems for financial risks
4. Financial decisions are often not data-driven  

# Core Features
 1. Authentication & Authorization
    * Secure login system
    * Role-based access:
      * Admin (Business Owner)
      * Staff (Finance)

 2. Cashflow Management
    - Input & manage:
       - Income
       - Expenses
       - Accounts Receivable
       - Accounts Payable
    - Transaction status:
       - Paid
       - Scheduled
       - Overdue

  3. Cashflow Prediction
  - Predict cashflow up to **90 days ahead**
    - Based on:
      - Historical data
      - Scheduled transactions
      - Displays cashflow trends
  
  4. Risk Alert System
    - Early warning system when:
      - Negative cashflow is predicted
    - Dashboard based alerts
    
  5. Financial Simulation (What-if Analysis)
    - Simulate financial decisions
      - Example:
      - “What if we purchase equipment next month?”
    - Does not affect actual data
    
  6. Dashboard & Analytics
    -Data visualization:
      - Cashflow trends
      - Financial reports
    - Data-driven insights

  7. Notification System
    -Types of alerts:
      - Cashflow deficit warning
      - Payment due reminders
      - Financial risk alerts
