#FlowGuard

FlowGuard adalah Business Cashflow Prediction & Monitoring App berbasis web yang dirancang khusus untuk membantu UMKM 
dalam mengelola, memantau, dan memprediksi arus kas bisnis secara proaktif.

Target utama FlowGuard adalah membantu bisnis kecil:
  - Menghindari kehabisan kas
  - Mengambil keputusan finansial berbasis data
  - Mengurangi ketergantungan pada spreadsheet manual

#Vision
Menjadi financial decision assistant berbasis data untuk UMKM agar dapat mengelola cashflow dengan lebih cerdas dan 
terukur.

Insights:
1. Banyak bisnis kecil masih mengandalkan spreadsheet manual → rawan error
2. Sulit memprediksi kondisi kas ke depan (30–90 hari)
3. Minim sistem peringatan dini terhadap risiko defisit
4. Pengambilan keputusan sering tidak berbasis data
